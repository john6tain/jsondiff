Contact and support

JSON Diff is maintained as a small open-source developer tool. If you found a bug, want to request a guide topic, or need to report a problem with the site, use one of the contact paths below.

Best ways to get in touch

  • Bug reports: open an issue on the GitHub repository with the browser, operating system, and a small sample payload if it is safe to share.
  • Feature requests: open a GitHub issue describing the workflow you are trying to support, not just the button you want added.
  • Security or privacy concerns: use GitHub to reach the maintainer, and avoid posting sensitive payloads publicly. The tool runs locally in the browser, so a reproducible shape-only sample is usually enough.

What to include in a useful report

A good report includes the page URL, the action you took, what you expected to happen, and what actually happened. For diff issues, include minimal JSON that shows the problem after replacing private values with harmless placeholders. For example, change real names, tokens, IDs, and account numbers before posting.

Maintainer and project details

The project is maintained by John6tain. Source code is available at github.com/john6tain/jsondiff. The site has no accounts, no login, and no support queue; issues are handled as time permits.

Advertising and content questions

If you are contacting the project about advertising, sponsorship, or content corrections, please include the exact page involved and the change you recommend. The goal of the site is to keep the comparison tool useful first: ads, if enabled in the future, should never interrupt the input panels or make JSON payloads harder to read.
